# Wavelength — Music Library Manager

## 1. Project Overview

Wavelength is a simple music library management system built with PHP, PDO, MySQL, HTML, and basic Tailwind CSS styling.

The system allows an administrator to view artists, albums, tracks, and playlists. It also provides features for adding tracks, editing artists, and deleting tracks.

The project was created as part of the Introduction to Databases & PHP course.

---

## 2. Technologies Used

- PHP
- MySQL / MariaDB
- PDO
- phpMyAdmin
- HTML
- Basic Tailwind CSS
- Laragon
- VS Code

No PHP framework or Composer package is used.
